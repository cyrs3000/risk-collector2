# risk-collector2

جمع‌آورنده‌ی ساعتی داده برای داشبورد «اتاق پایش ریسک منطقه».

- `collect.py` هر ساعت (GitHub Actions، دقیقه‌ی ۱۷ هر ساعت UTC) این منابع را بدون هوش مصنوعی می‌خواند:
  ADS-B (۱۰ نقطه)، NASA FIRMS (سه سنجنده)، بازارها (برنت، طلا، VIX، S&P، شِکِل، TA-35)، دلار و سکه (tgju)،
  فید خبری ۱۴ رسانه + ۱۵ جست‌وجوی Google News، ۲۶ کانال عمومی تلگرام، Safe Airspace و Polymarket.
- خروجی: `data/digest.json` (خلاصه‌ی فشرده‌ی ۱۲ تا ۲۴ ساعت اخیر، خط پایه‌ی ۱۴روزه و هشدارهای خودکار)،
  `data/state.json` (حافظه‌ی بین اجراها) و `data/archive/` (بایگانی روزانه).
- هشدارها فقط تطبیق کلیدواژه یا عبور از خط پایه‌اند و باید پیش از استفاده تأیید شوند.
- کلید FIRMS فقط در Secrets (`FIRMS_KEY`) است، نه در کد.
